# Note on this anonymized copy

These are the GPT-3 Small-shaped six-segment run's saved records (releases 0.8.15 to 0.8.24), with library and
author names replaced for double-blind review. The records are hash-chained and listed in a manifest, so replacing
those names changes their bytes: the manifest hashes and the preceding-line hash links verify on the unredacted
originals, not on this copy. `checker-result.json` is the evidence checker's report on the originals; every check
passed. The originals and their SHA-256 manifest are released with the camera-ready version. Every recorded value
the paper compares (state and gradient digests, loss bits, learning-rate bits, checkpoint SHA-256 values) is
unchanged in this copy. `live-h100-mi325x/` is the live segment in which an H100 coordinator and an MI325X worker
trained the same steps together.
